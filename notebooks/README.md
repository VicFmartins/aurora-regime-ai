# Notebooks

Os notebooks deste projeto sao destinados a exploracao, prototipagem e validacao visual de hipoteses. A recomendacao e manter aqui apenas analises temporarias ou checkpoints de pesquisa, promovendo codigo reutilizavel para `src/` assim que a abordagem amadurecer.

Convencoes sugeridas:

- comecar nomes com prefixos numericos;
- registrar objetivo e fonte de dados no topo;
- evitar dependencia de arquivos locais fora de `data/`;
- mover logica consolidada para modulos versionados.
