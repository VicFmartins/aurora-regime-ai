# Prompts GenAI

Espaco reservado para documentar o uso de GenAI no projeto, incluindo:

- prompts para sumarizacao de pesquisas;
- prompts para apoio exploratorio;
- regras de reproducibilidade;
- limites de uso para evitar inferencias nao auditaveis em etapas criticas.

O papel de GenAI no Aurora deve ser complementar a analise quantitativa, nunca substituindo validacao estatistica ou controle metodologico.
